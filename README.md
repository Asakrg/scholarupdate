# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ac1b149c-567c-4968-80d7-9d5191d35a1a

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `FIRECRAWL_API_KEY` in `.env` to your Firecrawl API key
3. Run the app:
   `npm start`
